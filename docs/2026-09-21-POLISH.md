# Targeted post-build polish — September 21, 2026

## Implemented scope
- Home is a fixed single screen with its original four Guided Flow entries, enlarged responsive mascot/ring, labels and fixed tabs. Lower feature cards removed. At 320×568 the hint clears the navigation; at 402×874 the ring uses the larger composition.
- Custom breathing remembers one valid rhythm locally and supports Reset. Zero holds are omitted from the generated preparation tutorial.
- Preparation uses Get ready, current phase durations, a 56–72px countdown and three soft rings driven by countdown changes. Pause/End are absent until active breathing; an interrupted preparation can Continue. Active engine timing is unchanged. Presentation settings live in assets/breathing.js.
- Mood sliders, rendered mixtures and detail proportions share normalized intensity. Existing 0–100 stored weights remain unchanged. The canonical 12-color selection lives in assets/emotion-palette.js; Content/Dreamy retain original historical identities/colors.
- Local calendar permissions replace rolling 24-hour Mood editing. Only missing yesterday can be backfilled; that backfill remains editable for the rest of today. Background/foreground and local midnight refresh eligibility, including a still-open editor.
- Week date selection gives its gummy one cancellable response; motion parameters live in assets/mood.js.
- Let It Out uses a centered secondary glass Keep this button. Its independent rolling 24-hour retention is unchanged.

## Platform limitation
This project is a browser app, without a native iOS host. Quiet Mode uses Screen Wake Lock after activation and releases it on exit, background and teardown. Browser support/system policy can refuse the lock. Native UIApplication.isIdleTimerDisabled requires a future native host integration; it is not implemented or verified on an iPhone here.

## Verification
Node regression tests cover custom persistence, normalized intensity round trips, exact palette and legacy identity, local-calendar backfill, midnight/DST boundaries, and wake-lock lifecycle/races, alongside existing app tests. Browser checks use 402×874 and 320×568 viewports plus isolated in-memory Mood records. No real user mood records are changed by the QA harness.
