# V1 增量规范 · 2026-09-16

本文件优先于 V1-SPEC.md 中冲突的旧说明。

## Home 固定入口

- I'm anxious → Extended Exhale（吸 4 / 呼 6）→ 3 秒倒计时 → 3 分钟会话。
- I can't sleep → Brown Noise → 自动播放，提供 Timer。
- Quiet my mind → 174 Hz 频率音 → 自动播放，提供 Timer。
- 第四项 Custom → 自定义呼吸设置。用户尚未定义第四项的组合流程；当前不增加 Routine。
- Mascot 双击仍进入 Brain Dump，长按仍进入 Overstimulation。

## 呼吸设置

直接展示 Box 4/4/4/4、4/7/8、Coherent 5/5、Physiological Sigh、Slow、Sleep 和 Custom。
Sigh 暂用 3/1/6，Slow 暂用 4/6，Sleep 暂用 4/8；这些是本轮实现默认值，图片没有指定这三种的秒数。
Custom：吸气、吸后停顿、呼气、呼后停顿；吸/呼 1–30 秒，停顿 0–30 秒，0 表示跳过。时长预设及自定义独立于节奏设置。切换音乐或时长不丢失自定义节奏。

音乐为直接可见的四个按钮：No music / Rain / Ocean / Soft music。默认无音乐，选择后会话开始时播放，结束时停止。当前均为本地 Web Audio 合成音景，非自然录音或完整曲目。频率音不作疗效声明。

声音页已从骨架升级为基本播放：Brown Noise / Frequency / Rain / Ocean / Soft music，播放暂停，Timer Off / 5 / 15 / 30 / 60 分钟。切换页面会停止；Timer 使用墙钟到期时间。iOS 后台自动暂停、声音品质和真机音频仍需验证，不能保证锁屏后持续播放。
