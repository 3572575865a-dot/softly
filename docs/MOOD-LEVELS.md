# Mood · 三层时间逻辑（当前有效规范）

本文件覆盖早期 Month / Year 全局汇总和 Add Mood 说明。

## 数据

唯一持久数据：本机 localStorage 的 `softly-mood-v1` daily entries。Week / Month / Year 全部实时派生，不存第二套统计数据。保留已有记录。

- Week：所选周一至周日恰好七颗，未记录日期仅生成透明视觉对象。
- Month：过滤所选自然月内的日期；按周一开始的日历行分组。逐周累加原始 emotion weight，每个非零的“月份 + weekIndex + emotionType”各生成一颗。不同周同色情绪不会合并。
- Year：过滤所选自然年，累加原始 emotion weight，每种非零情绪仅一颗，最多十二颗。尺寸使用年度相对权重。
- 每日混色仍用归一化比例；并列以首选情绪决定表情。汇总不展示数值或比例条。

## 创建与修改

今天无记录：Make Today。今天记录在编辑窗口内：Remake。两者共用编辑器，最多三种情绪、相对滑块、可选备注。

首次创建时 `editableUntil = createdAt + 24 hours`。每次保存再次验证窗口；Remake 不改变截止时间。旧记录缺少 editableUntil 时由 createdAt 推导。过期记录只读，不允许创建过去/未来日期的记录。历史记录若仍在 24 小时内可从 gummy 回看入口修改。

Save 后自动回 Week、本周、今天选中。新建只有一次轻柔落下声；Remake 更新原日期对象，以色彩交叠、表情替换和微晃动呈现，不增加对象、不播放新建声。

## 视觉与交互

Week 大小由 jar 内宽推导，七颗采用稳定的 2 / 2 / 3 排布与微小旋转。Month、Year 分别使用受限的非线性尺寸范围；Month 跨周使用同一尺寸基准，使同一情绪权重 7 大于权重 3。全部非零对象均显示，不截断为五颗。较密集的 Month 罐身延长以保证点击和识别，页面可滚动。

三个视图均可通过底部轻晃按钮或在罐内横向拖动触发短时物理模拟：重力、碰撞、轻回弹、旋转与阻尼。较大 gummy 的质量更大、运动较慢；约 2.4 秒停止计算。初始排布确定，不因刷新随机重排。

视图切换淡出后重建派生对象，再柔和淡入；不播放新建声音。Reduce Motion 禁用晃罐、落下和弹跳，保留信息和简单渐隐。

## 验证

自动测试包含用户的六颗月度示例、相邻月份隔离、年度十二种情绪、24 小时边界、不延长窗口、重复保存的身份、跨年周、响应式及高密度布局。

浏览器验证：Make Today → Save → Week / Today / Remake；Remake → Save 后恰好七颗；刷新保留记录；Month 显示周身份；Year 无重复情绪；晃罐按钮与玻璃日历可用。测试在 127.0.0.1 的独立浏览器存储运行，不写入 localhost 的用户记录。iPhone 真机帧率和触摸手感尚未测量。
